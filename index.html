Geographic provenance. Country, state/province, locality, and mapped coordinates in this release are derived from locality metadata associated with linked parasite records. They are not independently retrieved authoritative host metadata. Future releases will join host GUIDs directly to authoritative host records.
About this atlas

Each map point represents a host record linked to one or more independently cataloged parasite records. Filters retain hosts having at least one linked parasite record satisfying the active criteria. Absence of records should not be interpreted as biological absence.
